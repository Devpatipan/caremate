# เพิ่มลำโพงพูดไทยให้กล่อง CareMate (DFPlayer Mini)

ค่าเริ่มต้นกล่องใช้ **buzzer** (เสียงตี๊ด) ทำงานได้เลยไม่ต้องต่ออะไร
ถ้าอยากให้กล่อง **พูดไทย** ("ถึงเวลาทานยาแล้วค่ะ") หรือ **เล่นเสียงลูกหลานอัดเอง**
ต้องเพิ่มโมดูลลำโพง DFPlayer Mini ตามคู่มือนี้

> ถ้ายังไม่พร้อมต่อลำโพง เปิดไฟล์ `main.py` ตั้ง `USE_DFPLAYER = False` ไว้ก่อน กล่องจะใช้ buzzer ปกติ

---

## อุปกรณ์ที่ต้องซื้อ (~100-150 บาท)

| อุปกรณ์ | จำนวน | หมายเหตุ |
|---------|-------|----------|
| DFPlayer Mini (โมดูล MP3) | 1 | หาซื้อได้ตามร้านอิเล็กทรอนิกส์/ออนไลน์ |
| ลำโพง 8Ω 0.5-3W (เล็ก) | 1 | ต่อเข้า DFPlayer ได้เลย |
| การ์ด microSD (เล็กสุดก็พอ 1-8GB) | 1 | ฟอร์แมตเป็น FAT32 |
| ตัวต้านทาน 1kΩ | 1 | คั่นสาย TX กันสัญญาณแรงเกิน (แนะนำ) |
| สายจัมเปอร์ตัวเมีย-ตัวเมีย | 4-5 | ต่อระหว่างบอร์ด |

---

## การต่อสาย (DFPlayer ↔ KidBright32)

DFPlayer Mini มี 16 ขา แต่ใช้แค่ 6 ขานี้:

| ขา DFPlayer | ต่อไปที่ | หมายเหตุ |
|-------------|----------|----------|
| **VCC**  | 5V (VIN/USB 5V ของ KidBright) | ถ้าไม่มี 5V ใช้ 3V3 ได้ แต่เสียงเบากว่า |
| **GND**  | GND | กราวด์ร่วม |
| **RX**   | GPIO **17** (ผ่านตัวต้านทาน 1kΩ) | ESP32 TX -> DFPlayer RX |
| **TX**   | GPIO **18** | (จะต่อหรือไม่ก็ได้) |
| **SPK_1**| ขั้วลำโพง + | |
| **SPK_2**| ขั้วลำโพง − | |

```
  KidBright GPIO17 ──[ 1kΩ ]── RX  DFPlayer  SPK_1 ──┐
  KidBright GPIO18 ───────────  TX  Mini      SPK_2 ──┴── ลำโพง 8Ω
  5V  ───────────────────────  VCC
  GND ───────────────────────  GND
```

> **หมายเหตุ:** ขา GPIO 17/18 เป็นค่าเริ่มต้นในเฟิร์มแวร์ (แก้ได้ที่ `PIN_DF_TX`, `PIN_DF_RX` ใน `main.py`)
> ถ้าขาชนกับอย่างอื่นบนบอร์ดของคุณ ให้เปลี่ยนเป็นขาว่างอื่น

---

## เตรียมไฟล์เสียงลงการ์ด microSD

1. ฟอร์แมตการ์ดเป็น **FAT32**
2. สร้างโฟลเดอร์ชื่อ `mp3` (ตัวเล็ก) ที่รากการ์ด — หรือวางไฟล์ที่รากเลยก็ได้
3. ตั้งชื่อไฟล์เป็นตัวเลข 4 หลัก:

| ไฟล์ | เสียง | ตรงกับตัวเลือกในแอป |
|------|-------|---------------------|
| `0001.mp3` | "ถึงเวลาทานยาแล้วค่ะ" (เสียงพูดไทย) | เสียงพูดไทย |
| `0002.mp3` | เสียงลูกหลานอัดเอง | เสียงลูกหลานอัดเอง |

**วิธีทำไฟล์ 0001.mp3 (เสียงพูดไทย)** เลือกอย่างใดอย่างหนึ่ง:
- อัดเสียงตัวเองพูด "ถึงเวลาทานยาแล้วค่ะ" ด้วยมือถือ แล้วแปลงเป็น .mp3
- ใช้เว็บแปลงข้อความเป็นเสียง (TTS) ภาษาไทยฟรี พิมพ์ประโยค แล้วดาวน์โหลดเป็น .mp3

**ไฟล์ 0002.mp3** = ให้ลูกหลานอัดเสียงเอง(เช่น "แม่ กินยาด้วยนะครับ") แล้วก๊อปลงการ์ดในชื่อนี้

> เสียบการ์ดเข้า DFPlayer ให้เรียบร้อยก่อนเปิดเครื่อง

## ตั้งค่าในเฟิร์มแวร์

เปิด `main.py` ตรวจส่วนนี้ (ค่าเริ่มต้นถูกอยู่แล้ว):
```python
USE_DFPLAYER = True     # เปิดใช้ลำโพง
PIN_DF_TX = 17
PIN_DF_RX = 18
DF_VOLUME = 25          # ดังไป/เบาไป ปรับ 0-30
```
แล้ว **Deploy device-poll ใหม่** (เพราะเพิ่มการส่งค่าเสียงที่เลือก):
```bash
npx supabase functions deploy device-poll --no-verify-jwt
```
จากนั้นอัปโหลด `main.py` ลงบอร์ด (Thonny → Save as → MicroPython device → main.py) แล้ว reset

## ใช้งาน

1. ในแอป → แท็บ **อุปกรณ์** → เลือกเสียง **"เสียงพูดไทย"** (หรือ "เสียงลูกหลานอัดเอง")
2. พอถึงเวลายา กล่องจะ**พูด**แทนเสียงตี๊ด (เล่นซ้ำทุก ~6 วิ จนกดปุ่ม)
3. เปลี่ยนกลับเป็น **"เสียงติ๊ด (Buzzer)"** เมื่อไหร่ก็ได้ กล่องรับค่าใหม่ในรอบ poll ถัดไป

## แก้ปัญหา

| อาการ | วิธีแก้ |
|-------|---------|
| ไม่มีเสียงพูด (ยังตี๊ดอยู่) | ดู Shell ว่าขึ้น `DFPlayer พร้อม` ไหม ถ้าขึ้น `ต่อไม่ได้` = ตรวจสาย TX(17)/GND/VCC |
| ขึ้น `DFPlayer พร้อม` แต่เงียบ | การ์ดไม่ถูกฟอร์แมต FAT32 / ชื่อไฟล์ไม่ใช่ `0001.mp3` / ลำโพงหลวม |
| เสียงเบา | ต่อ VCC เข้า 5V (ไม่ใช่ 3V3) และเพิ่ม `DF_VOLUME` |
| เสียงแตก | ลด `DF_VOLUME` เหลือ ~20 หรือใช้ลำโพงวัตต์สูงขึ้น |
| อยากกลับไปใช้ตี๊ดอย่างเดียว | ตั้ง `USE_DFPLAYER = False` แล้วอัปโหลดใหม่ |
