# กล่องเตือนยา CareMate บน KidBright32

กล่อง KidBright ทำหน้าที่เป็น "นาฬิกาปลุกยา" ให้ผู้สูงอายุที่บ้าน โดยไม่ต้องพึ่งมือถือ
เมื่อถึงเวลายา กล่องจะ **ส่งเสียง buzzer + ไฟกระพริบ** และผู้สูงอายุกดปุ่มบนบอร์ดเพื่อยืนยัน
ผลจะถูกส่งกลับขึ้นคลาวด์ ให้ลูกหลานเห็นในแอปทันที

```
  แอป CareMate ──ตั้งเวลายา──▶  Supabase (คลาวด์)  ◀──ถามทุก 20 วิ── กล่อง KidBright
        ▲                                                                  │
        └──────────────── เห็นผล "ทานแล้ว/เลื่อน" ◀──── กดปุ่ม S1 / S2 ─────┘
```

กล่องคุยกับคลาวด์ผ่าน 2 Edge Functions โดยยืนยันตัวด้วย `DEVICE_KEY` (ไม่ใช้บัญชีผู้ใช้)
จึงปลอดภัยและแยกข้อมูลของผู้ป่วยแต่ละคน

- `device-poll` — กล่องถามว่า "ถึงเวลายาไหมตอนนี้"
- `device-confirm` — กล่องส่งผลการกดปุ่ม (ทานแล้ว / เลื่อน)

---

## ปุ่มบนกล่อง

| ปุ่ม | ความหมาย | ผลที่ backend |
|------|----------|----------------|
| **S1** (สวิตช์ซ้าย) | ทานยาแล้ว | บันทึก `taken` (source = box) |
| **S2** (สวิตช์ขวา) | ขอเลื่อน 10 นาที | บันทึก `snoozed` — กล่องจะเงียบ 10 นาทีแล้วเตือนซ้ำ |

---

## ขั้นตอนติดตั้ง

### 1) Deploy Edge Functions ขึ้น Supabase (ทำครั้งเดียว)

ที่โฟลเดอร์โปรเจกต์ (มี `supabase/` อยู่):

```bash
supabase functions deploy device-poll --no-verify-jwt
supabase functions deploy device-confirm --no-verify-jwt
```

> ต้องใส่ `--no-verify-jwt` เพราะกล่องยืนยันด้วย `device_key` เอง ไม่ได้ล็อกอินผู้ใช้
> ทั้งสองฟังก์ชันใช้ `SUPABASE_SERVICE_ROLE_KEY` ที่ Supabase ใส่ให้อัตโนมัติ ไม่ต้องตั้งเพิ่ม

### 2) จับคู่กล่องในแอป เพื่อได้ `DEVICE_KEY`

เปิดแอป CareMate → แท็บ **อุปกรณ์** → เพิ่ม/จับคู่กล่อง
ระบบจะสร้างแถวในตาราง `devices` พร้อม `device_key` และผูกกับผู้ป่วยที่กำลังดูแล
คัดลอกค่า `device_key` ไว้ใช้ในขั้นตอนที่ 4

### 3) แฟลช MicroPython ลงบอร์ด KidBright32 (ครั้งเดียว)

1. โหลดเฟิร์มแวร์ MicroPython สำหรับ **ESP32** จาก https://micropython.org/download/esp32/
2. ติดตั้งเครื่องมือและลบของเก่า แล้วแฟลช (เปลี่ยน `COM3` เป็นพอร์ตของคุณ):

```bash
pip install esptool
esptool.py --chip esp32 --port COM3 erase_flash
esptool.py --chip esp32 --port COM3 --baud 460800 write_flash -z 0x1000 ESP32_GENERIC-xxxxxxxx.bin
```

> Windows ดูพอร์ตที่ Device Manager (เช่น COM3) · macOS/Linux มักเป็น `/dev/ttyUSB0`
> ถ้าต่อไม่ติด ให้ลงไดรเวอร์ CP210x หรือ CH340 ตามชิป USB ของบอร์ด

### 4) แก้ค่าตั้งต้นใน `main.py`

เปิด `main.py` แก้ 4 บรรทัดบนสุด:

```python
WIFI_SSID = "ชื่อ WiFi ของคุณ"
WIFI_PASS = "รหัส WiFi"
SUPABASE_URL = "https://kxsujkyxuxierctfatpu.supabase.co"
DEVICE_KEY = "วางรหัสอุปกรณ์จากขั้นตอนที่ 2"
```

> ⚠️ WiFi ต้องเป็นคลื่น **2.4GHz** (ESP32 ไม่รองรับ 5GHz)

### 5) อัปโหลดไฟล์ลงบอร์ด

ใช้ **Thonny** (ง่ายสุด) หรือ `mpremote`:

**Thonny:** เปิด Thonny → เมนู Run → เลือก interpreter เป็น *MicroPython (ESP32)* และพอร์ตให้ถูก
→ เปิด `main.py` → Save as → เลือก *MicroPython device* → ตั้งชื่อ `main.py`

**mpremote (คอมมานด์ไลน์):**
```bash
pip install mpremote
mpremote connect COM3 fs cp main.py :main.py
```

ต้องมีไลบรารี `urequests` บนบอร์ดด้วย (เฟิร์มแวร์บางรุ่นมีให้แล้ว) ถ้าไม่มี:
```bash
mpremote connect COM3 mip install urequests
```

### 6) รีเซ็ตบอร์ด

กดปุ่ม reset (EN) หนึ่งครั้ง กล่องจะ:
- เสียง "ปี๊บ" สั้น ๆ ตอนบูต
- ไฟกระพริบระหว่างต่อ WiFi แล้วนิ่งเมื่อต่อสำเร็จ
- จากนั้นถามคลาวด์ทุก 20 วินาที

---

## ทดสอบว่าใช้งานได้

1. ในแอป เพิ่มยา 1 รายการให้ผู้ป่วยคนที่ผูกกับกล่อง โดยตั้ง **เวลาตอนนี้** (เช่นอีก 1 นาที)
2. รอถึงเวลา กล่องจะส่งเสียงเตือนและไฟกระพริบ
3. กด **S1** → เสียงตอบรับสูง ๆ แล้วเงียบ · เปิดแอปดู จะเห็นสถานะ "ทานแล้ว" (จากกล่อง)
4. ลองกด **S2** ในรอบถัดไป → กล่องเงียบ 10 นาทีแล้วเตือนซ้ำ

ดู log ระหว่างพัฒนาได้ที่ Thonny (Shell) หรือ:
```bash
mpremote connect COM3 repl
```

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|-------|------------------|
| ไฟกระพริบไม่หยุด ต่อ WiFi ไม่ติด | เช็คชื่อ/รหัส WiFi และต้องเป็น 2.4GHz |
| log ขึ้น `DEVICE_KEY ไม่ถูกต้อง` (403) | `DEVICE_KEY` ไม่ตรงกับในตาราง `devices` — จับคู่ใหม่ในแอปแล้วคัดลอกใหม่ |
| ถึงเวลาแล้วไม่เตือน | เวลาบนเซิร์ฟเวอร์ใช้โซน Asia/Bangkok · หน้าต่างเตือนคือ 30 นาทีหลังเวลายา · ตรวจว่ายัง `active` |
| เสียงไม่ออก / ปุ่มไม่ตอบ | เลขขา GPIO ไม่ตรงรุ่นบอร์ด — ลองปรับ `PIN_BUZZER`, `PIN_SW1`, `PIN_SW2` ใน `main.py` |
| กด S1 แล้วแอปไม่อัปเดต | ยังไม่ได้ deploy `device-confirm` หรือ deploy โดยไม่ใส่ `--no-verify-jwt` |

> **หมายเหตุเรื่องขา GPIO:** ค่าเริ่มต้น (Buzzer=13, S1=16, S2=14) อ้างอิงบอร์ด KidBright ทั่วไป
> KidBright บางล็อต/รุ่นวางขาไม่เหมือนกัน ถ้าเสียงหรือปุ่มไม่ทำงานให้ลองปรับเลขขา
> ตรวจได้ด้วยสคริปต์สั้น ๆ ใน REPL เช่น `print(machine.Pin(16, machine.Pin.IN, machine.Pin.PULL_UP).value())` แล้วกดปุ่มดูค่าเปลี่ยน
