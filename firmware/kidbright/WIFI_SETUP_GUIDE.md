# กล่อง CareMate — ตั้ง WiFi ผ่านมือถือ (ไม่ต้องแตะโค้ด)

เฟิร์มแวร์ตัวนี้มีระบบตั้งค่าในตัว ไม่ต้องแก้ WiFi/DEVICE_KEY ในโค้ดอีกต่อไป

---

## สำหรับคนทำ (ทำครั้งเดียวต่อกล่อง)

1. แฟลช MicroPython ลงบอร์ด (ถ้ายังไม่เคย)
2. อัปโหลด `main.py` ตัวนี้ลงบอร์ด (Thonny → Save as → MicroPython device → `main.py`)
3. จบ — ไม่ต้องกรอก WiFi ในโค้ด ส่งกล่องให้ผู้ใช้ได้เลย

> `SUPABASE_URL` ฝังไว้ในโค้ดแล้ว (คงที่) — สิ่งที่ผู้ใช้กรอกคือ WiFi บ้าน + DEVICE_KEY เท่านั้น

---

## สำหรับผู้ใช้ (ตั้งค่าครั้งแรก)

1. **เสียบไฟกล่อง** — ไฟจะกระพริบช้า ๆ (โหมดตั้งค่า) และมีเสียงปี๊บ 2 ครั้ง
2. เปิด **มือถือ** → ตั้งค่า WiFi → เลือกเครือข่ายชื่อ **`CareMate-Setup`**
3. หน้าเว็บตั้งค่าจะ**เด้งขึ้นเอง** (ถ้าไม่เด้ง เปิดเบราว์เซอร์พิมพ์ `192.168.4.1`)
4. ในหน้านั้น:
   - เลือก **WiFi บ้าน** (2.4GHz) จากรายการ หรือพิมพ์ชื่อเอง
   - ใส่ **รหัส WiFi**
   - วาง **รหัสอุปกรณ์ (device key)** — เอามาจากแอป CareMate ▸ แท็บ **อุปกรณ์**
   - กด **บันทึกและเริ่มใช้งาน**
5. กล่องรีสตาร์ตเอง ต่อ WiFi บ้าน แล้วเริ่มทำงาน — เสร็จ! ไม่ต้องต่อคอมเลย

---

## อยากเปลี่ยน WiFi / ตั้งค่าใหม่

**กดปุ่ม S2 ค้างไว้ตอนเปิดเครื่อง** (หรือตอนกดปุ่ม reset)
กล่องจะล้างค่าเดิมและกลับเข้าโหมดตั้งค่า (`CareMate-Setup`) ให้กรอกใหม่

> กล่องจะเข้าโหมดตั้งค่าเองด้วย ถ้าต่อ WiFi ที่บันทึกไว้ไม่ได้ (เช่น ย้ายบ้าน/เปลี่ยนรหัส WiFi)

---

## ไฟบอกสถานะ

| ไฟ LED | ความหมาย |
|--------|----------|
| กระพริบช้า สม่ำเสมอ | อยู่ในโหมดตั้งค่า (รอมือถือมาตั้ง WiFi) |
| กระพริบถี่ตอนเปิด | กำลังต่อ WiFi บ้าน |
| กระพริบสั้นเป็นจังหวะ ~20 วิ | ทำงานปกติ (heartbeat) กำลังเฝ้าเวลายา |

---

## เกร็ดเทคนิค (ทำงานยังไง)

- โค้ดไม่มี WiFi ฝังไว้ — ค่าที่ผู้ใช้กรอกถูกเซฟเป็นไฟล์ `caremate_cfg.json` บนตัวกล่อง
- ตอนตั้งค่า กล่องทำตัวเป็น Access Point + เว็บเซิร์ฟเวอร์เล็ก ๆ + DNS ที่เด้งทุกหน้าเว็บมาที่หน้าตั้งค่า (captive portal)
- บูตครั้งต่อไปกล่องอ่านไฟล์แล้วต่อ WiFi เอง — **โค้ดไม่เคยเปลี่ยน เปลี่ยนแค่ไฟล์ตั้งค่า**
